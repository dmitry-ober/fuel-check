# Fuel Check

An offline cross-check of the Garmin "Fuel on Destination" figure for a Cirrus SR22T. It is a simple installable web app that works without a connection once loaded. It is not a primary fuel computer.

**Cross-check only — fly the Garmin.**

Live app: https://dmitry-ober.github.io/fuel-check/

## Install on iPhone / iPad

1. Open the live URL in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Launch it once from the home screen while online so it caches for offline use.

## Updates

Open the new version once while online. The service worker cache name is bumped on each deploy, so the new files replace the old cache on that visit.
